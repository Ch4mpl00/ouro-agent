# Design documents

Non-trivial changes start here, by the process the ouro engine uses
([ouro `docs/designs/README.md`](https://github.com/Ch4mpl00/ouro/blob/main/docs/designs/README.md),
adapted from Google's Elephant-Goldfish Model): one long-context session writes
`docs/designs/NN-name.md` from the template there; reviewers with no prior
context check it by the rubric in ouro's `docs/designs/REVIEW.md` (read this
repository's `CLAUDE.md` instead of ouro's `AGENTS.md`, and its main principle:
the runtime informs, the agent decides); the maintainer settles open points;
executors with a fresh context implement strictly by the document.

The repository is public: no server addresses, chat ids, emails, personal
amounts or secrets in a design document.
