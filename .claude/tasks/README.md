# tasks/

Design records: decisions, their reasons and the alternatives we rejected,
for work that shipped or is under way. Code and docs point at them. Open
work lives in GitHub issues (see CLAUDE.md, Task tracking); a record whose
work is not finished links its issue under **Open work**.

New work starts as an issue, not a file here. A record's "why" moves into
code comments next to the code it constrains over time; a record nobody
points at any more is deleted (git history keeps it).

This repository is public: no server addresses, credentials, chat ids,
account numbers or amounts, and nothing personal about the user.
